# 🚀 HR Comércio - Website Institucional

Website institucional da **HR Comércio**, desenvolvido com foco em design futurista e experiência visual moderna.
O projeto apresenta os serviços da empresa, projetos realizados e um formulário de contato para novos clientes.

## 📌 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web básicas:

* **HTML5** – Estrutura do site
* **CSS3** – Estilização e design responsivo
* **JavaScript** – Interatividade e animações
* **Google Fonts** – Tipografia personalizada

## 📁 Estrutura do Projeto

```
site_hr/
│
├── index.html      # Estrutura principal do site
├── styles.css      # Estilos e layout visual
├── script.js       # Funcionalidades e animações
└── README.md       # Documentação do projeto
```

## ⚙️ Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/VitorGirottto/hr_comercio
```

2. Acesse a pasta do projeto:

```bash
cd site_hr
```

3. Abra o arquivo `index.html` no navegador.

Exemplo:

* Clique duas vezes no arquivo **index.html**
* Ou utilize uma extensão como **Live Server** no VS Code.
